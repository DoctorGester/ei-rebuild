# Typing in the UTF-8 build (EI_UTF8, ticket U4; docs/notes/standalone.md section 4): the game window is a
# Unicode one, so characters typed into the console's line arrive as UTF-16 WM_CHAR ("typeunicode" posts them
# as Windows gives a Unicode window a typed character; a character past U+FFFF as a surrogate pair), are
# stored as UTF-8, and the caret, Backspace and Delete go by character ("consoleline" checks the line's bytes
# and the caret's place). Without EI_UTF8 both steps are skipped and the console is only opened and closed.
# The line is drawn and measured with the wide GDI calls (U3): a Greek letter (outside the assets' code page
# 1251) draws as itself, not as the '?' an ANSI call would make of it ("utf8 diffcapture": the frames of the
# line "λ" and the line "?", the caret after either and the menu's scene frozen, differ only by the glyph; the
# steps marked "utf8" run in the UTF-8 build only).
