# R9c: full screen in the switch-over (docs/notes/renderer.md, section 9): at 800x600 the game window
# covers the monitor without a display mode change and the frame is scaled into it with its aspect;
# the menus and the battle screen take the mapped mouse. The focus lost and given back (Alt+Tab as
# Windows reports it: WM_ACTIVATE inactive and the window minimised, then restored and activated):
# the game deactivates (the display mode "restored" through the stand-in), and on its return
# rebuilds the cursor (005DAE70, full screen only) and draws and presents again. A window resized
# by someone else (a display change) covers the monitor again at the next present. run_all runs a
# "resolution" scenario alone.
