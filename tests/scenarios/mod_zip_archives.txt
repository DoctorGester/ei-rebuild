# A mod shipped as one zip (docs/notes/mods.md, "Zip mods"): rebirth_mod_archives' mod (tools/make_mod_s19d.py
# archives) packed into the run's harness_saves\s19d_mod.zip, its files at the zip's root (its .res archives stored,
# the rest deflated), which "mod" makes the settings' Mod (either install). The zip is read in place as the mod's
# folder: config.reg's [RES] lists name the mod's archives inside it, opened from the zip's bytes, and every answer is
# rebirth_mod_archives' (its goldens and this one's are the same: the saves in harness_saves\s19d_mod\, the zip's name
# without ".zip").
# prepare: make_mod_s19d.py archives --zip s19d_mod.zip
mod harness_saves\s19d_mod.zip
reject Script error
waitmenu
modfile texts.res s19d.txt 7
modfile texts.res s19d_b.txt 11
modfile texts.res map.txt +
modlist texts.res s19d* 3
modfile outro.res outro_mod.txt 18
modfile outro.res credits.scr 0
modfile outro.res outro.rtf 0
modlist outro.res * 1

console thingamabob
newgame
waitfor 15 IsGreater(HP(GetLeader()),0)
modarchive figures unmodr.anm 11
modarchive links unmodr.anm 11
modarchive figures s19d.fig 19
modarchive links s19d.fig 19
modarchive figures s19d_tex.mmp 30
modarchive links s19d_tex.mmp 30
modarchive figures s19d_t2.mmp 0
modarchive textures s19d_tex.mmp 30
modarchive textures s19d_t2.mmp 7
modarchive textures armytent01.mmp 43764
modarchive textures s19d.fig 0
modarchive textures unmodr.anm 0
check IsAlive(GetLeader())
report
quit
