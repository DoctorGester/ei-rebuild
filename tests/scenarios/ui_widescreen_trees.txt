# Rebirth's WideScreen layout takes the resolution the game itself loaded (src/game/ui_widescreen.h Configure, called
# with the options' VideoResolution): the game's option tree on the original's data, Rebirth's starter tree on its data
# (NivalRegistry). The run's settings file gives the two trees different sizes (treeresolution, tests/verify/harness_settings.h),
# a wide one (1600x900) in the game's and another (1920x1080) in the starter's; the layout must log the size of
# the tree the install reads.
# no original: vanilla rebirth (the layout is the image's; the original's addon.dll reads only the starter tree)
timeout 40
deterministic
widescreen 1
rebirthflags WideScreen
treeresolution game 1600x900
treeresolution starter 1920x1080
reject Script error
waitmenu
wait 500
expectlog ifnot=NivalRegistry WideScreen: 1600x900, 4:3 part 1200
expectlog if=NivalRegistry WideScreen: 1920x1080, 4:3 part 1440
report
quit
