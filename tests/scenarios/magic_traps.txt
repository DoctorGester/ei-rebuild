# Magic traps (src/game/magic_trap.cpp, tickets U3 / U7 / U8). zone1 has none, and AddMob of the
# whole zone2.mob stalls the original (one of zone2's other objects), so before the run
# tools/make_trap_mob.py writes traps.mob into the run's harness_saves: zone2's seven magic traps
# (MTF1..4, MTFW, MTLW, MTPF) and nothing else, renumbered 30001..30007 so they do not take the ids
# of zone1's own objects (a clash crashes the original when save1 loads; see the tool). The zone
# loader does not register traps by name, so the checks find them with GetObject(id). AddMob (LoadMobFile 00595AB0) takes
# a name relative to <game root>maps\ (00595BA0 / 0055E990), so "..\saves\traps.mob" opens
# <game root>saves\traps.mob, which the harness redirects to harness_saves. The traps go through
# the factory (Construct 00529DD0) and SetUp (0052A2C0); zone2's map is smaller, so their
# positions lie inside zone1. MTF4 (a lightning trap, one circle of radius 3 at 43, 104) is armed
# with a wolf placed in it, so UpdateVictims, FindTrapVictims and CastAtUnits can run and the list
# of units inside may hold it when the game saves. The escape menu's Save writes save1 (SaveTrap
# 0052B070 for every trap); loading save1 removes the map objects (DestructBody 00529F90 through
# the deleting destructor) and reads the traps back (Construct, LoadTrap 0052ADC0).
# prepare: make_trap_mob.py
waitmenu
console thingamabob
newgame
waitline 15 Saved savea
waitfor 15 IsGreater(HP(GetLeader()),0)
console @BlockUnit(GetLeader(),0)
console @GodMode(0,1)

console @AddMob("..\saves\traps.mob")
waitfor 10 IsEqual(GetObjectID(GetObject(30004)),30004)
check IsEqual(GetObjectID(GetObject(30001)),30001)
check IsEqual(GetObjectID(GetObject(30007)),30007)
console @AddUnitToServer("TrapWolf","WolfTutor","TrapWolf",43,104,0)
console @ActivateTrap(GetObject(30004),1)
wait 2000

# Escape menu, Save (as ui_saveload.txt): OK (region 0) saves into save1.
key esc
waitwindow 10 escmenu
click 395 120
waitwindow 10 saveload
clickregion 0
waitline 10 Saved save1
# A wolf that is not in save1 tells when the load has replaced the world.
console @AddUnitToServer("TrapMarker","WolfTutor","TrapMarker",Add(GetX(GetLeader()),8),GetY(GetLeader()),0)
waitfor 5 IsAlive(GetObjectByName("TrapMarker"))

load save1
waitfor 15 Mul(Not(IsAlive(GetObjectByName("TrapMarker"))),IsGreater(HP(GetLeader()),0))
# The loaded world in full (a golden checkpoint, tests/golden; standalone-verification.md, SV3).
dump loaded_save1
check IsEqual(GetObjectID(GetObject(30004)),30004)
check IsEqual(GetObjectID(GetObject(30001)),30001)
report
quit
