# Lost in Astral's cut-scene bases on Gipat and Ingos, cz0k to cz2k (MOD2a; docs/notes/mods.md, "Lost in Astral
# played (MOD2)"), from the story's own state: the party Gipat (the hero Hero3 and the mercenary merc2g, member
# "merc2"). Each base's briefing is read to the end (talk) and the base leaves for the zone its script names (gz21k
# each time); the briefing's variable is checked there. cz3k, cz4k and Jigran's cz1j are mod_lost_in_astral_cz_ingos_end
# (H70: the six bases in one game took 24 s alone and passed the 60 s limit on a full machine). One digest record, in
# cz2k (a small zone; the others are checked by their variables). On the vanilla data only the menu runs.
# Only on Rebirth's data: the vanilla run checks nothing another scenario does not.
# installs: rebirth
mod starter\Mods\LostInAstral
reject Script error
waitmenu
digest off
rebirth console thingamabob
rebirth newgame
rebirth waitfor 20 IsGreater(HP(GetLeader()),0)
rebirth waitline 20 Saved savea
rebirth waitwindow 15 battle

rebirth console @CreateParty(0,"Gipat")
rebirth console @AddUnitToParty(0,"Gipat::Hero","Hero3")
rebirth console @AddUnitToParty(0,"Gipat::merc2","merc2g")
rebirth console @SetCurrentParty(0,"Gipat")
rebirth console @RedeployParty(0)
rebirth waitfor 10 IsAlive(GetObjectByName("merc2"))

rebirth zone cz0k 0
rebirth waitzone 25 cz0k
rebirth check IsAlive(GetObjectByName("merc2"))
rebirth waitdialogue 30 3
rebirth talk 40
rebirth waitzone 40 gz21k
rebirth check IsEqual(GSGetVar(0,"b.merc2.brief_200"),2)

rebirth zone cz1k 0
rebirth waitzone 25 cz1k
rebirth waitdialogue 30 3
rebirth talk 40
rebirth waitzone 40 gz21k
rebirth check IsEqual(GSGetVar(0,"b.Trader.brief_205"),1)

rebirth zone cz2k 0
rebirth waitzone 25 cz2k
rebirth waitdialogue 30 3
rebirth digest
rebirth talk 40
rebirth waitzone 40 gz21k
rebirth check IsEqual(GSGetVar(0,"b.His.brief_210"),1)
rebirth check IsAlive(GetObjectByName("merc2"))
report
