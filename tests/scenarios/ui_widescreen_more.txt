# Rebirth's WideScreen, part two (ticket W2; ui_widescreen.txt is part one, docs/notes/rebirth.md
# "WideScreen"): the places addon scales without the margin and the shapes, on screen for
# comparison with Rebirth's own frames:
#   python tools\run_all.py --widescreen
# runs ui_widescreen and this under Rebirth with our hooks and with --no-hooks (addon's code only)
# and compares the frames. Same settings as part one (the desktop's mode, WideScreen on, the
# virtual clock); a frame with a "_later" twin is compared without what moved between the two.
# On screen: every text (005FDE20, 005F8340) and sprite shape (005E70E0 / 005E7680 / 005E7D60 /
# 005E99D0); the multiplayer hero screen's name field (the edit field 0065C2E0); a tooltip at the
# battle screen's right edge (0065E580); the console; the Esc menu's Save window with the new
# save's caret (the list 006567A0). The battle screen's panels are built while addon's panel
# builders set the panel offset (the shapes' x). The chat line (005E3700) is opened by the harness
# for its verify wrapper, which compares its pixels with addon's: a single player game does not
# show it. The Save window pauses the world: what moved in save_moving / save_moving_later, captured
# before it opened, is left out of its frame (run_all).
