# Rebirth's WideScreen, part four (ticket W4; docs/notes/rebirth.md "WideScreen"): the other screens,
# for comparison with Rebirth's own frames:
#   python tools\run_all.py --widescreen
# runs this with the other ui_widescreen scenarios under Rebirth with our hooks and with --no-hooks
# (addon's code only) and compares the frames. Same settings as part one (the desktop's mode,
# WideScreen on, the virtual clock); a frame with a "_later" twin is compared without what moved
# between the two, one with "_moving" / "_moving_later" without what moved before its window opened.
# On screen here: the multiplayer hero screen's list (its mode 00615D30 hides the curtains over the
# margins there; the new hero, where they show, is in ui_widescreen_more); two zone tutorial
# messages whose pulsing frames point at the battle screen's panels and follow them to the screen's
# edges (00659420+574: "zt4" at the right panels, both pages; "zt9" at the left ones), each queued
# with the script's SendStringEvent ("tutorial <name>", as the zones' scripts do) and opened with
# the message key (H: the harness keeps the tutorial option off, so a queued message does not open
# by itself; the key shows the last one); then the global map's mouse moves (00630010, its pick
# picture read without the margin) and a right-button drag turning it (the drag's motion scaled
# without the margin). Not captured: its scene is lit by the world's time, which differs between
# the runs.
