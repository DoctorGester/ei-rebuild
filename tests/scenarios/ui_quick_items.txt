# Quick items and spells on a target (docs/notes/ui.md, "Eighteenth pass (ticket I9)"): two wands
# go into the hero's quick slots through the camp, then the battle screen uses them on a unit and
# at a point, and a spell aimed at a point is cast on the ground.
#
# The wands: "wand 3" (category 5) with lightning (spell kind 'u', flag 0x10000000) and with a
# fireball (kind 't'). The camp (screen 5) page 0 puts a quick item from the item strip on the hero
# (PutOn 0060FCA0, at most four); the harness step campputon does what a click on each wand in the
# camp's item strip does (the camp's slot 42, MoveItem mode 1). Back in the game the quick item panel shows the
# hero's four quick items at x 670..720, 620..670, 570..620, 520..570 (y 550..600); a click on one
# (button release 0063DB20 -> 0063DD70) starts mode 3 (a lightning wand: on a unit, 00637500 with
# quick 1) or 4 (the fireball wand: at a point, 00637750 with quick 1). Each slot is clicked, then
# the ground (a mode 4 item is used there; mode 3 waits) and then a wolf (a mode 3 item is used on
# it; otherwise a plain order), so the order of the items does not matter.
#
# The spell: the hero gets only the fireball, so the spell column has one button (760..800 x
# 470..510). SetUnit leaves it highlighted, and a click on the highlighted spell cancels, so the
# button and the ground are clicked twice: one of the two clicks starts mode 2 (no flag
# 0x10000000) and the ground click casts it at the point (SelectUnit -> 00637750).
# Coordinates are the 800x600 layout. The game runs ~5.5x faster (10 ms per world update).
