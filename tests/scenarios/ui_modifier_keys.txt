# Clicks and keys with modifier keys held (harness steps hold / release and the <mods> words after
# a step's arguments, docs/notes/ui.md section 10). The game takes Ctrl / Shift / Alt from the window
# messages (CInterface3D +0x7C / +0x7D / +0x7E), so the real keyboard never matters.
#   Shift + the hero's portrait toggles the member's selection (ToggleMember 006379E0).
#   Ctrl + spell key 1 casts the hero's fireball at once (kActionSpell: CHudSpellColumn::ClickAlternate
#   0063EF60) on the nearest wolf the hero sees; Alt + quick item key P uses the first wand at once
#   (CHudQuickItems::UseNow 0063E020); the same with the modifier held by hold / release over frames.
#   Shift + a unit click (SelectUnit with Shift down) and Ctrl + Shift together.
# The setup is ui_quick_items': two wands in the hero's quick slots through the camp, the fireball
# spell, two blocked wolves beside the hero. Coordinates are the 800x600 layout.
reject Script error
waitmenu
console thingamabob
newgame
waitfor 15 IsGreater(HP(GetLeader()),0)
console @BlockUnit(GetLeader(),0)

console @GiveItem(0,"wand 3.iron[lightning]")
frames 5
console @GiveItem(0,"wand 3.iron[fireball]")
frames 5

# The camp (page 0): both wands on the hero, as clicks on them in the item strip do (the

screen 5

console @GSSetVar(0,"hy",GetY(GetLeader()))
console @GiveUnitSpell(GetLeader(),"fireball")
frames 5
