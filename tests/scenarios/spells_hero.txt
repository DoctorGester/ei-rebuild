# Spells cast by the hero (a caster, unlike script casts): the arrow's missile (CEffectArrow,
# world_effect_missile.cpp) starts at the caster's effect point on the client, and vision fog makes
# a CEffectShowVisibility (world_effect_visibility.cpp) linking the hero and the target. The report's
# call counts show what was reached (CEffectArrow / CEffectShowVisibility Tick, Pack, Unpack).
#
# Giving the spells: GiveUnitSpell does not work on the hero. It puts the spell into the unit's own
# slots (CUnit::AddSpell 00531820), but a party unit's spells are read from its player's party
# record (CUnit::GetSpell 005319A0), so the column kept the hero's own two spells (healing 0x18 and
# 0x0C). The spells are given as "spell container[<spell>]" items (GiveItem, FindItem 006AC970) and
# put on in the camp's magic page (page 1, region 5), as clicks in its item strip do; that page's
# CanEquip (006100E0) wants the spell's level within the school's skill, hence the GiveSkill lines.
# The column then holds healing, 0x0C, vision fog (0x17) and the fire arrow (0): four buttons at
# (780, 370), (780, 410), (780, 450) and (780, 490) (hudstate logs the slots).
#
# The hero must not be blocked: the server drops orders, casts included, of a unit with flag
# 0x800000 (BlockUnit; 0066FFF0). The zone's intro script blocks the hero for ~37 s: wait for that
# block and lift it. Or() is a Rebirth addon function (vanilla: "Parameter of type float
# expected"), so the checks use plain comparisons.

console @GiveSkill(GetLeader(),"sense",5)
console @GiveSkill(GetLeader(),"astral",5)
console @GiveIntelligence(GetLeader(),60)
console @GiveItem(0,"spell container[vision_fog]")
frames 5
console @GiveItem(0,"spell container[arrow{e2}]")
frames 5
