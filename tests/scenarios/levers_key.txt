# Locks and keys (LockKey::Opens 00522A80 through Lever::KeyOpens 0052BBA0 and Lever::ApplyKey 0052BB50;
# standalone-verification.md, SV5b). zone1's gate lever 1889 gets locks of the three kinds a key can meet:
# by id (mask 8): the key fits, the id differs, the lever has no lock; the hero is put next to it.
# The quest item "Palantir" (id 8, the player's list; hudstate prints the id) shows in the quick item
# panel's top row (region 4, x 670..720, y 500..550; Rebirth's widescreen layout puts it at 700..750) when the leader is selected; picking it starts
# mode 6 ("use on an object"), whose hover (KeyOpens through the cursor) and click (KeyOpens, then the
# order whose use action is ApplyKey) are exercised on the lever (clickunit "#1889": a map object by id).
# (A key's level branch is out of reach: a quest item's key has mask 8 only, and a locked lever refuses
# the plain click that would carry mask 1.)
reject Script error

console @GSSetVar(0,"lx",GetX(GetObject(1889)))
console @GSSetVar(0,"ly",GetY(GetObject(1889)))
console @GSSetVar(0,"lv",GetLeverState(GetObject(1889)))
console @SetCPFast(GetLeader(),Sub(GSGetVar(0,"lx"),3),GSGetVar(0,"ly"),GetZValue(Sub(GSGetVar(0,"lx"),3),GSGetVar(0,"ly")))
