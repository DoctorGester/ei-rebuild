# Rebirth's StreamPatch and MoviesPatch (S19d; src/engine/mods/mod_folders.h, docs/notes/rebirth.md "Resources and paths")
# with a mod of our own: tools/make_mod_s19d.py stream writes it into the run's harness_saves\s19d_mod, which "mod"
# makes the settings' Mod (either install). The mod's Stream\ holds s19d.mp3 (a track the game has no
# file of) and bravery.mp3 (a track it has); its Movies\ holds crdtfin.bik (a movie it has). The files are copies of
# the install's own; the checks are the trace of the files the game touches (tests/verify/harness_modtrace.h): a path
# the stream opens or a movie opens maps through the harness, so the folder the game chose shows there. The mod's own
# paths are also asked about (IsFile) before the choice, so a mod file is checked together with the game's path for the
# same name: the mod's file touched and the game's not.
# - StreamPatch, at the main menu: "playstream" asks the music stream for a track as the menu's music does. The stream
#   steps run on the virtual clock (no device in a harness run, SV5d6), so the wait takes the same world updates every run
#   and the goldens record them. s19d.mp3 opens the mod's file; bravery.mp3
#   the mod's copy, not the game's; attack.mp3, which the mod does not have, the game's.
# - MoviesPatch, in the game: PlayMovie("crdtfin.bik") plays the mod's movie (the console line returns when it ends;
#   the mod's copy is progres.bik's, a short one); a movie the mod does not have comes from the game's folder.
# prepare: make_mod_s19d.py stream
mod harness_saves\s19d_mod
reject Script error
waitmenu
playstream s19d.mp3
waitread 15 mod Stream\s19d.mp3
read game Stream\s19d.mp3 no
playstream bravery.mp3
waitread 15 mod Stream\bravery.mp3
read game Stream\bravery.mp3 no
playstream attack.mp3
waitread 15 game Stream\attack.mp3

console thingamabob
newgame
waitfor 15 IsGreater(HP(GetLeader()),0)
console @BlockUnit(GetLeader(),0)
console @PlayMovie("crdtfin.bik")
read mod Movies\crdtfin.bik yes
read game Movies\crdtfin.bik no
console @PlayMovie("titles.bik")
read game Movies\titles.bik yes
wait 500
check IsAlive(GetLeader())
report
quit
