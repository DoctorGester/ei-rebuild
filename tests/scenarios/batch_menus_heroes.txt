# ---- section utf8_typing
# The image's UTF-8 text (docs/notes/standalone.md section 4). File names (U2): "utf8files" makes, lists, reads
# back and removes a folder and a file with Cyrillic names through the game's file calls. Typing (U4): characters
# typed into the console's line arrive as the platform's UTF-8 text ("typeunicode" hands each in as a Text event, a
# character past U+FFFF too), are stored as UTF-8, and the caret, Backspace and Delete go by character ("consoleline" checks the line's bytes
# and the caret's place). The line is drawn and measured with the wide GDI calls (U3): a Greek letter (outside
# the assets' code page 1251) draws as itself, not as the '?' an ANSI call would make of it ("diffcapture": the
# frames of the line "λ" and the line "?", the caret after either and the menu's scene frozen, differ only by
# the glyph). The text audit (U5): "utf8text" checks Cyrillic case-insensitive compares and case changes by the
# UTF-8 case table and the player name filter; "chatwrap" adds a long Cyrillic chat line (a word wider than a
# line among them) to the chat overlay and requires valid UTF-8 lines that join back to it.
