# Interface gallery, in a game (ticket N4; docs/notes/ui-native.md, "N4: the gallery"): the battle
# screen's windows, each held still (freeze) and captured. Frames: hud (unit panel, the map with its
# marker pixels, the top, movement and weapon panels, the frame rate surface of "fps on"),
# quest_notice (a quest line in the message log), top_page2 (the top panel's second page), hud_tip

# caret), objectives (the zone page with a quest), help (the objectives' help page), escmenu (the
# escape menu over the greyed backdrop), save (the save window: list, picture, the name edit field),
# load (the load window's list with two
# saves and a picture), view (screen 7, the debug view). The hero cannot be hurt (zone1's wolf).
