# The hero dies in single player: CUnitServer::UpdateServer (00552300) finds the dead unit is the
# party's leader (CPlayer::IsLeader) and runs the player connection's slot 20, CPlayerServer::
# OnLeaderDied (0066F4C0): message 0x09 and 0x0B with the hero's id to the client (the game-over
# path). The report's call count for CPlayerServer::OnLeaderDied must be 1.
reject Script error
waitmenu
console thingamabob
newgame
waitfor 15 IsGreater(HP(GetLeader()),0)
console @BlockUnit(GetLeader(),0)
console @InflictDamage(GetLeader(),100000)
# The death and the game-over messages take some 150 world updates.
wait 10000
report
quit
