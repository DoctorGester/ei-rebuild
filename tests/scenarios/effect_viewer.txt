# The effect viewer (ei-effects; docs/modding.md, "The effect viewer"; MF15i, MF15k4) on the showcase mod, driven by
# its commands (src/tools/effect_viewer.cpp, Command; tests/verify/effects/effects_harness.cpp). Checked:
# - an original type on data (Portal, its built-in file) plays at a free point by the camera's focus: particles;
#   pause, scrub and step land on the ticks asked for;
# - a field edited (emit.rate, the Fields window) plays again from the start up to the same tick, and the file is
#   saved into the run's output folder (never the install): `replace = true` and the edited rate in it;
# - a mod's data effect (showcase_aura, from the mod's Res\effects) on the figure, driven through its typed inputs (the
#   enum `mode` by its value's name, the float `charge`, the event `pulse`): stepped through its first stages;
# - a script edited on disk (MF15f1): showcase_hooks.lua, in the mod's copy in the run's folder, rewritten by the
#   harness so that on_start sets `burst` (the stage flare at once): a scan reads it again and the effect plays it up to
#   the same tick; rewritten without hooks, a save reads it again (the stage glow);
# - an original type with a carrier's motion (Tornado, its built-in file) plays on the figure walking its circle;
# - captures: the docked windows over each.
# exe: ei-effects
# prepare: make_showcase_mod.py
mod harness_saves\showcase_mod
frames 5
effectviewer pick Portal
effectviewer place focus 3 0 0
wait 1500
effectviewer expect particles 20
capture viewer_portal
frames 3

effectviewer pause
effectviewer scrub 40
effectviewer expect tick 40
effectviewer step 5
effectviewer expect tick 45
effectviewer field emit.rate size * 30
effectviewer expect problems 0
effectviewer expect tick 45
effectviewer expect particles 100
effectviewer tab text
effectviewer play
frames 3
capture viewer_portal_edited
frames 3
effectviewer folder out viewer_mod
effectviewer save
effectviewer expect status saved
effectviewer tab fields

effectviewer pick showcase_aura
effectviewer place figure
effectviewer pause
effectviewer step 5
effectviewer expect stage rise
effectviewer step 20
effectviewer expect stage glow
effectviewer play
effectviewer input mode storm
effectviewer input charge 1
frames 3
effectviewer fire pulse
wait 600
effectviewer expect particles 20
capture viewer_aura
frames 3

effectviewer pick showcase_hooks
effectviewer place focus 3 0 0
effectviewer pause
effectviewer step 5
effectviewer expect stage glow
write harness_saves\showcase_mod\Res\effects\showcase_hooks.lua local hooks = {}\nfunction hooks.on_start(e) e:set("burst", 1) end\nreturn hooks
effectviewer scan
effectviewer expect tick 5
effectviewer expect stage flare
write harness_saves\showcase_mod\Res\effects\showcase_hooks.lua return {}
effectviewer save
effectviewer expect tick 5
effectviewer expect stage glow

effectviewer pick Tornado
effectviewer place figure
effectviewer figure walk on
effectviewer figure run on
wait 800
effectviewer expect particles 5
effectviewer expect problems 0
capture viewer_tornado
frames 3
effectviewer figure walk off
effectviewer figure run off

effectviewer new viewer_new
effectviewer expect problems 0
effectviewer place focus 3 0 0
effectviewer append [[on]]\nevent = "tick"\nwhen = "age == 3"\ndo = [{ effect = "Teleport" }]
effectviewer expect problems 0
effectviewer pause
effectviewer scrub 9
effectviewer expect children 1
effectviewer expect subparticles 100
wait 600
effectviewer expect subparticles 100
effectviewer scrub 9
effectviewer expect subparticles 100
effectviewer play
wait 300
capture viewer_new
frames 3
report
quit
