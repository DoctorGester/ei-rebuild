# Rebirth's WideScreen, part three (ticket W3; docs/notes/rebirth.md "WideScreen"): the battle
# screen's panels used, for comparison with Rebirth's own frames:
#   python tools\run_all.py --widescreen
# runs this with ui_widescreen and ui_widescreen_more under Rebirth with our hooks and with
# --no-hooks (addon's code only) and compares the frames. Same settings as part one (the desktop's
# mode, WideScreen on, the virtual clock); a frame with a "_later" twin is compared without what
# moved between the two.
# The panels' builders set the panel offset (the map, the quick items, the spell column and the
# clock at the screen's right edge; the unit panel, the weapon bar, the action column and the
# movement panel at its left) and move their layout constants. On screen here: a weapon slot
# clicked (0063C050), the unit panel's info page (its draw 006462A0, many texts), a movement
# mode (00649910), a click on the map (00645210: the camera looks at that point), both side panels
# slid out and back in (their layouts and updates 00642930 / 00642B40 / 00645F80 / 00647FB0).
# Coordinates: the harness's 800 x 600 points spread over the whole screen; at the desktop's
# 3840 x 2160 a point x is at layout x * 4/3 - 133.3 (the 4:3 part, 2880 pixels, in the middle; the
# panels move by 134 layout units). Each step names the layout point it aims at.
deterministic
