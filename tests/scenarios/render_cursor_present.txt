# R40: the game's cursor as the system's (docs/notes/renderer.md section 9). Each frame hands the renderer its cursor
# picture's current frame (005E54A0 -> render::Cursor); the present shows it as an SDL colour cursor made at the
# window's scale and through the gamma ramp, one per picture frame. A present without one hides it: as in the original,
# the movie players and every loading screen step hide the image (005E5270 0). While the game holds its cursor still
# (the camera turned with the right button, 005E67B0) the cursor is held at the game's position.
#
# "cursorcheck" reads the shape the harness's platform backend was given (harness_platform.cpp): "shown" checks its
# size and hot spot against the game's image at the window's scale and, with a name, writes the last frame with the
# cursor drawn in; "hidden", "held" and "animated" count the presents since "cursormark". "windowtitle" checks the
# window's title ("Evil Islands") and class name ("EIGAME"). "cursormark" also keeps the shapes shown from then on while the gamma
# ramp is the identity (the picture has 24 frames); "cursorcheck - gamma" checks that the shape shown now is one of them
# through the gamma ramp the present applies.
render checkall
resolution 800x600
fullscreen 0
reject Script error
waitmenu
windowtitle
console thingamabob

# The main menu, one to one.
move 400 300
frames 10
cursormark
frames 5
cursorcheck menu shown 5

# The gamma ramp reaches the shape: the options' gamma slider held changes the ramp, the
# shape is made again through it; Cancel puts the old value back and the shape returns to the marked one.

ldown 674 336
wait 600
lup 674 336
waitpresent 10 gamma
move 400 20

clickregion 1
waitwindow 10 menu
move 400 300
waitpresent 10
frames 10
cursorcheck - gamma
