# Rebirth's ResOverride lists beyond S19b's one string (S19d; src/game/mod_folders.h, docs/notes/rebirth.md "Resources
# and paths") with a mod of our own: tools/make_mod_s19d.py archives writes it into the run's harness_saves\s19d_mod, and
# "addonpath" answers the starter's Settings\AddonPath with that folder. config.reg [RES]:
#   texts.res    = [Res\s19d_texts_a.res, Res\s19d_texts_b.res]   an array: the mod's archives in order, then the game's
#   outro.res    = [Res\s19d_outro.res, "-"]                      a mod archive, and the game's own switched off
#   figures.res  = Res\s19d_figures.res                           an extra figure archive, before the game's
#   textures.res = Res\s19d_textures.res                          overrides the game's archive, also an extra texture one
#   menus.res    = Res\s19d_menus.res                             an extra figure archive (before) and texture one (after)
# At the main menu "modfile" and "modlist" open the game's archive as the game does and look a file up or list it
# through the mod's archives; in the game "modarchive" asks the figure manager's, the link figure loader's and the
# texture manager's archives (with the mod's extra ones among them) for a file, in their order. The vanilla install has
# no mod loader: the same lines give the game's files only.
# - texts.res: s19d.txt is in both mod archives (7 and 13 bytes): the first one's; s19d_b.txt only in the second; the
#   game's own file (map.txt) still comes; the listing holds the three mod names and none of the game's.
# - outro.res: the mod's file comes; the game's credits.scr and outro.rtf read as missing, and the listing is the
#   mod's one name (the game's two without a mod: "-" ignores the archive for GetFile and ListFiles alike).
# - Figures: unmodr.anm (the dragon's animation, a name the game's figures.res has too) is the mod's 11 bytes, from the
#   figure manager and the link loader alike; s19d.fig only the mod's; menus.res' s19d_tex.mmp is a figure archive
#   file too, and no figure archive holds the texture archives' own s19d_t2.mmp.
# - Textures: armytent01.mmp is in the game's textures.res, which comes before the mod's extra archives (and the mod's
#   textures.res: the override puts the mod's archive first, so its copy is not the 8 bytes of menus.res' one, which
#   is behind the game's three; the game's copy is 43764 bytes in the vanilla and Rebirth data); the mod's s19d_tex.mmp
#   (menus.res) and s19d_t2.mmp (textures.res) are found; the figures' s19d.fig and unmodr.anm are not.
# prepare: make_mod_s19d.py archives
addonpath s19d_mod
reject Script error
waitmenu
rebirth modfile texts.res s19d.txt 7
rebirth modfile texts.res s19d_b.txt 11
vanilla modfile texts.res s19d.txt 0
modfile texts.res map.txt +
rebirth modlist texts.res s19d* 3
vanilla modlist texts.res s19d* 0
rebirth modfile outro.res outro_mod.txt 18
rebirth modfile outro.res credits.scr 0
rebirth modfile outro.res outro.rtf 0
rebirth modlist outro.res * 1
vanilla modfile outro.res outro_mod.txt 0
vanilla modfile outro.res outro.rtf +
vanilla modlist outro.res * 2

console thingamabob
newgame
waitfor 15 IsGreater(HP(GetLeader()),0)
rebirth modarchive figures unmodr.anm 11
rebirth modarchive links unmodr.anm 11
rebirth modarchive figures s19d.fig 19
rebirth modarchive links s19d.fig 19
rebirth modarchive figures s19d_tex.mmp 30
rebirth modarchive links s19d_tex.mmp 30
rebirth modarchive figures s19d_t2.mmp 0
rebirth modarchive textures s19d_tex.mmp 30
rebirth modarchive textures s19d_t2.mmp 7
rebirth modarchive textures armytent01.mmp 43764
rebirth modarchive textures s19d.fig 0
rebirth modarchive textures unmodr.anm 0
vanilla modarchive figures unmodr.anm +
vanilla modarchive links unmodr.anm +
vanilla modarchive figures s19d.fig 0
vanilla modarchive links s19d.fig 0
vanilla modarchive textures s19d_t2.mmp 0
vanilla modarchive textures armytent01.mmp +
check IsAlive(GetLeader())
report
quit
