# The drawn motion of objects and the blend between animations (R19; docs/notes/renderer.md section 14, "Objects"
# and "Animation blends"). At a fixed frame time of 8 ms (a 120 Hz screen's frames on the virtual clock):
# - the hero walks (captures moving_*): a unit is placed on its path at each frame's time, so it is drawn where it
#   is and moves without a jump, also over a new path's start (its own place jumps there once; the drawn one fades);
# - vanilla: the hero, with a bow, shoots a wolf standing with the blends off (its right hand "rh3" jumps at the
#   switch into the attack), then walks and shoots a second one with them on (captures walk_attack_*: no jump); the
#   bow's arrow moves only in client ticks (its own place jumps at each one), the draw spreads each tick's step;
# - the hero stands until an idle plays, then sets off (captures idle_run_*: idle, the cross into a walk, the walk;
#   the hand without a jump).
# Captures are 5 frames (40 ms) apart.
# Only on the vanilla data: the Rebirth run reaches no code and checks nothing the vanilla run does not.
