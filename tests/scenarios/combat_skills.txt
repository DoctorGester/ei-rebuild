# Combat orders the player gives from the battle screen (H43a, coverage gaps of H43): a wand used on a
# unit (CastOn with a quick item source: UnitServer::SpellCarrier, UseItemCharge), the science button on
# a unit outside the party, which is a steal order (PlayerMode::CommandUse, UnitServer::OrderSteal, then
# UseSkill: "Item has been stolen from" for a unit that carries a quest item), a run order given with a
# double click, and a move order given while the game is paused (UnitServer::OrderMove plans the way at
# once, PlanMove; PauseGame(0) pauses). Taming is not here: the original cut it (docs/notes/combat.md,
# "Original bugs kept"), no order the interface gives reaches it.
# The hero is unblocked (the server drops a blocked unit's orders) and in god mode; the wolves stand
# blocked. Coordinates are the 800x600 layout. No `speed`, so a golden can be recorded.

# A run order: a double click on a unit (the first click, then the double click's second half) orders the
# hero to run at it (the order's run flag; UnitServer::TakeQueuedOrder checks CanStillDo for it).
console @AddUnitToServer("SkillWolf2","WolfTutor","SkillWolf2",Sub(GSGetVar(0,"hx"),5),GSGetVar(0,"hy"),0)
