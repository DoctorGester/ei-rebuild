# The save / load window's Delete and a load from it (A-H14; docs/notes/ui.md, "Objectives, save/load,
# options"): after the new game's autosave (savea) a save into a new folder (save1, Confirm on
# the new save's row), then in the Load window the first row is selected, Delete asks (AskDelete),
# Enter answers yes (DeleteSave: the folder's files and the folder go, the list is refilled), the
# remaining save is selected and OK loads it (Confirm -> LoadSelected). The rows' titles come from
# the zone / allod texts (ZoneTitle, AllodTitle). Rectangles from menus.reg; rows are regions 3...

console thingamabob
newgame
speed 10
waitline 15 Saved savea
waitfor 15 IsGreater(HP(GetLeader()),0)
waitwindow 15 battle

# Escape menu, Save: OK (region 0) on the new save's row saves into save1.

waitwindow 10 escmenu

waitwindow 10 saveload
clickregion 0
waitline 15 Saved save1
waitwindow 10 battle
