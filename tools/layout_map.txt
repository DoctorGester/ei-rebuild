# Where every file of the flat src/game went (C168; the plan and its rules: docs/notes/file-layout.md).
# tools/layout.py checks this file against src/game and src/engine and writes the listing in the notes; the batches
# moved by it.
#
# A line: OLD NEW [OP] [# why]. OLD is a file name of the flat src/game (or, for `new`, the flat name a split batch
# gives a new file); NEW its path after the moves: under src/engine for the engine's folders (core, data, models,
# scene, mods, particles; MF15k1c), else under src/game. OP:
#   (none)  moved under the same name; a name change says why (a meaning rename)
#   fold    OLD's content joins NEW, which another line moves there (thin split of one class or subject)
#   split   OLD is divided by meaning in a split batch (C168b, C168c); NEW keeps OLD's main part, `# ->` the rest
#   new     a file a split batch creates (flat, under OLD), moved to NEW with its folder
#
# `batch ID: folder ...` lines give each folder's move batch.

batch C168d: core data mods saves
batch C168e: app console sound world players map
batch C168f: ai combat objects units
batch C168g: items spells effects particles terrain models scene
batch C168h: script net ui
