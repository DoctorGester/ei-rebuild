# ei_settings.ini

Generated by tools/gen_settings_doc.py from src/engine/data/settings_catalog.inc. Do not edit.

The game keeps its settings in `ei_settings.ini` next to the exe (on macOS in
`~/Library/Application Support/ei-rebuild`; or in `%LOCALAPPDATA%\EvilIslands` when that folder cannot be
written). Each `[section]` holds `name = value` lines; a line starting with `;` or `#` is a
comment. When the file is missing or empty the game writes the defaults, each line with its description above
it; it never adds comments to a file that exists. A value the file lacks takes the default below.

Defaults: what the game takes when the line is absent; a new file holds the lines marked *(new file)*.

The original game's settings this build does not read (a file that holds them keeps the lines; the game
ignores them): [video] VideoZBufferDepthInBits, VideoRefreshRate, Antialiasing, Dithering, PerspectiveCorrection, ShowParticles, FPSIndependentCursor, AutomaticQuantization, MovieCapturingFPS, DrawingTarget, VideoColorDepthInBits, Specular, TextureQuality, Mipmapping, Filtering, Contrast, [shadows] ShadowQuality, HeroShadow, UnitShadow, BuildingShadow, FloraShadow, OtherShadow, LightingFreq, FloraSpecialLight, [terrain] EnableDynamicLights, ShadowingFreq, EnableWaterWaves, EnableSelfShadowing, EnableFootprints, EnableBloodprints, EnableFireprints, EnableBloodprintsRelight, LightingFreq, [game] Joystick, UseSWCursors, CornerSize, CD1 Label, CD3 Label, Font CharSet, DrawVisibleOnly, Keyboard Layout, ObjectsLightingCoeff, Hero Light R/G/B/Radius, Quest Light R/G/B/Radius, DefaultWindForce, DefaultTimeScale, DefaultMapName, DefaultStreamingSound, FogNightStartDistance, FogDayStartDistance, [camera] FarClipDistance, [statistics] CreateOutputInfo, NumberOfFrames.
